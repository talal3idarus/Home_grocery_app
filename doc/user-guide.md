# User Guide

Welcome to the Home Grocery App! This guide will help you make the most of all the features available in the app.

## 🚀 Getting Started

### First Time Setup

1. **Download and Install** the app on your Android device
2. **Create an Account** or **Login** with your existing credentials
3. **Grant Permissions** when prompted (for optimal functionality)
4. **Complete Initial Setup** in the Settings screen

### Main Interface Overview

The app consists of several main sections accessible through the navigation drawer:

- **🏠 Home**: Your main grocery list
- **📊 Analytics**: Shopping history and insights  
- **⚙️ Settings**: App preferences and configuration
- **🔔 Notifications**: App alerts and messages
- **👤 Account**: User profile and authentication

## 📝 Managing Your Grocery List

### Adding Items

#### Quick Add
1. Tap the **+ (Plus)** floating action button on the home screen
2. Enter the item name in the text field
3. Optionally set category and urgency level
4. Tap **Save** to add the item to your list

#### Detailed Add
1. Use the same **+ button** but fill in additional details:
   - **Name**: Item name (required)
   - **Category**: Select from predefined categories or create new
   - **Urgency**: Low, Medium, or High priority
   - **Description**: Additional notes about the item
   - **Tags**: Keywords for easier searching

### Organizing Items

#### Categories
Items can be organized into categories such as:
- 🥕 **Produce**: Fruits and vegetables
- 🥛 **Dairy**: Milk, cheese, yogurt
- 🍞 **Bakery**: Bread, pastries
- 🥫 **Pantry**: Canned goods, dry goods
- 🧊 **Frozen**: Frozen foods
- 🧽 **Household**: Cleaning supplies, toiletries

#### Urgency Levels
- **🟢 Low**: Can wait for next shopping trip
- **🟡 Medium**: Needed soon
- **🔴 High**: Urgent, needed immediately

### Managing Items

#### Editing Items
1. Tap on any grocery item card
2. Modify the details as needed
3. Tap **Save** to update

#### Completing Items
- **Single Item**: Tap the checkmark on the item card
- **Multiple Items**: Use bulk selection mode (long press to start)

#### Deleting Items
- **Single Item**: Swipe left on the item or use the delete button
- **Multiple Items**: Select multiple items and tap the delete button

### Search and Filtering

#### Search Functionality
1. Use the search bar at the top of the home screen
2. Type item names, categories, or tags
3. Results update in real-time as you type

#### Advanced Filtering
1. Use the filter dropdowns below the search bar:
   - **Category Filter**: Show only items from specific categories
   - **Urgency Filter**: Filter by priority level
2. Combine filters for precise results
3. Clear filters by selecting "All" options

## 📊 Shopping Analytics

### Viewing Your History

1. Navigate to **Analytics** from the drawer menu
2. Switch between **Analytics** and **History** tabs

#### Analytics Dashboard
- **Total Shopping Sessions**: Number of completed shopping trips
- **Average Items per Session**: How many items you typically buy
- **Average Spending**: Estimated spending per trip
- **Most Frequent Items**: Your commonly purchased items
- **Total Spent**: Cumulative spending estimate

#### Shopping History
- **Session List**: All your completed shopping trips
- **Session Details**: Tap any session to see items purchased
- **Date Sorting**: Most recent sessions appear first

### Understanding Analytics

#### Shopping Patterns
- **Frequency Analysis**: See which items you buy most often
- **Spending Trends**: Track your grocery spending over time
- **Shopping Frequency**: How often you complete shopping trips

#### Using Insights
- **Budget Planning**: Use spending data for budget planning
- **Shopping Optimization**: Identify frequently bought items
- **Pattern Recognition**: Understand your shopping habits

## ⚙️ App Settings

### Theme Customization

#### Dark/Light Mode
1. Go to **Settings** → **Appearance**
2. Toggle between **Light** and **Dark** themes
3. Changes apply immediately throughout the app

#### Theme Preferences
- **System Default**: Follow device theme settings
- **Always Light**: Force light theme
- **Always Dark**: Force dark theme

### Notification Settings

#### Managing Notifications
1. Navigate to **Settings** → **Notifications**
2. Enable/disable notification types:
   - **Shopping Reminders**: Alerts for incomplete items
   - **Sync Updates**: Data synchronization status
   - **App Updates**: New feature announcements

#### Notification Types
- **🔵 Info**: General information
- **🟢 Success**: Completed actions
- **🟡 Warning**: Important notices
- **🔴 Error**: Issues requiring attention

### Data Management

#### Backup and Restore

**Creating Backups**
1. Go to **Settings** → **Data Backup**
2. Tap **Create Backup**
3. Choose backup location (device storage)
4. Wait for backup completion

**Restoring Data**
1. In **Settings** → **Data Backup**
2. Tap **Restore from Backup**
3. Select backup file
4. Confirm restoration (overwrites current data)

#### Auto-Sync Settings
1. **Enable Auto-Sync**: Automatically sync when online
2. **Sync Frequency**: How often to sync with cloud
3. **WiFi Only**: Restrict sync to WiFi connections

### Account Management

#### Profile Settings
- **Email**: View/change registered email
- **Password**: Update account password
- **Account Info**: Basic account details

#### Privacy Controls
- **Data Sharing**: Control what data is shared
- **Analytics**: Opt in/out of usage analytics
- **Crash Reporting**: Help improve the app

## 🔧 Troubleshooting

### Common Issues

#### Data Not Syncing
1. **Check Internet Connection**: Ensure device is online
2. **Manual Sync**: Go to Settings → Sync Data
3. **Restart App**: Close and reopen the application
4. **Check Firebase Status**: Verify service availability

#### App Performance Issues
1. **Restart App**: Close completely and reopen
2. **Clear Cache**: Use device settings to clear app cache
3. **Free Storage**: Ensure device has sufficient storage space
4. **Update App**: Install latest version from app store

#### Login Problems
1. **Check Credentials**: Verify email and password
2. **Reset Password**: Use forgot password option
3. **Check Connection**: Ensure stable internet connection
4. **Clear App Data**: Last resort - will lose local data
