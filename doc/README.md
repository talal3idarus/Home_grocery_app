## 📱 About the App

The Home Grocery App is a Flutter-based mobile application designed to help users manage their grocery shopping lists efficiently. It features:

- ✅ Grocery item management with categories and urgency levels
- 📱 Offline-first design with Firebase sync
- 📊 Shopping history and analytics
- 🔐 User authentication
- ⚙️ Customizable settings
- 🌙 Dark/light theme support
- 📱 Material Design UI

## 🛠️ Technology Stack

- **Frontend**: Flutter/Dart
- **Backend**: Firebase Realtime Database
- **Authentication**: Firebase Auth
- **Local Storage**: SQLite (via sqflite)
- **State Management**: Provider pattern
- **Platform**: Android/iOS
